# 🎓  Study Group

**Study Group** is a Flutter-based educational social networking application designed to bring students together in one collaborative learning environment. The platform enables students to communicate through group chats, explore educational content, and interact with a personalized AI assistant to support their learning journey.

The project aims to make education more interactive and accessible by combining social networking, collaborative learning, and AI-powered assistance in a single application.

## ✨ Features

### 💬 Group Communication
- Chat with other students in groups.
- Collaborate and exchange ideas with fellow learners.
- Build a connected student community.

### 📚 Educational Feed
- Browse educational posts and learning materials.
- Discover content shared within the student community.
- Share knowledge and educational resources.

### 🤖 AI Assistant
- Interact with a personalized AI assistant.
- Ask questions and receive AI-generated responses.
- Get assistance with learning-related tasks.

## 🛠️ Tech Stack

- **Flutter** — Cross-platform mobile application development.
- **Dart** — Primary programming language.
- **BLoC / Cubit** — State management and separation of UI from application logic.
- **Firebase** — Backend services used for the features integrated into the application.
- **Appwrite** — Backend services used for the features integrated into the application.
- **Clean Architecture** — Separation of application responsibilities into independent layers to improve maintainability and testability.

## 🏗️ Architecture

The application follows Clean Architecture principles to organize the codebase into separate layers.

- **Presentation Layer:** Contains the UI and state management using BLoC/Cubit.
- **Domain Layer:** Organizes the core business logic and domain entities.
- **Data Layer:** Handles data sources, repositories, and communication with backend services.

This structure helps separate business logic from the UI and external services, making the application easier to maintain and extend.

## 🚀 Planned Features

The following features are planned for future development:

- 🔔 **Push Notifications:** Notify students about new messages, group activity, and important updates.
- 🎙️ **Voice-Controlled AI Assistant:** Allow students to speak to the AI assistant, ask questions, and perform supported actions through voice commands.
- 🏫 **Educational Institutions:** Introduce schools, universities, and educational institutes to the platform.
- 🤝 **Student–Institution Communication:** Enable students to connect and communicate with educational institutions through dedicated channels.
- 📈 **Enhanced Learning Experience:** Expand the platform with additional tools that support collaboration and learning.

## 🎯 Project Goals

- Build a collaborative learning community for students.
- Make educational content easier to discover and share.
- Integrate AI to support students in their learning activities.
- Apply software engineering principles to build a maintainable Flutter application.
- Expand communication between students and educational institutions.

## ⚙️ Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or Visual Studio Code
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd YOUR_PROJECT_DIRECTORY
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Configure the required Firebase and Appwrite credentials according to your project setup.

5. Run the application:

   ```bash
   flutter run
   ```
